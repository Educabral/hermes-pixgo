# Thread Format (X/Twitter) for Specialist Audiences

## When to Use
User says "quero post sobre [tema técnico] para grupo de especialistas" or "estilo thread no X".

## Structure
- 6-8 tweets
- Each tweet: 2-4 short paragraphs max
- Numbered: 1/8, 2/8, etc.
- Between tweets: 2-3 blank lines as visual separator
- Does NOT need `---` or any markdown separators

## Tone Rules for Specialist Posts
- Polished, grammatically correct
- Proper punctuation and accents (CRITICAL — user corrects this)
- Same analytical depth as PutinHO tone but cleaner delivery
- No profanity unless the topic demands it
- Data-driven, numbers verified
- Ends with a strong thesis, not a question

## Delivery
- `post_to_x.py` does NOT support threads natively — it opens 1 tweet intent per call
- Best option: write full thread to a .txt file, share path with user
- Alternative: paste each tweet in sequence on X manually

## Proofreading Checklist
- [ ] All accents correct (liquidação, oráculo, rebalanceamento, etc.)
- [ ] Punctuation correct (periods, commas, em-dashes)
- [ ] No run-on sentences
- [ ] Numbers formatted consistently (US$, %, BTC)
- [ ] Each tweet self-contained (doesn't require reading previous)
